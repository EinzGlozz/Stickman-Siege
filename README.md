# Stickman Siege

Version 2 des 2D-Stickman-Shooters mit 12 Levels, Bosskämpfen, Upgrades, zufälligen Deckungen und einer Kamera, die der Spielfigur folgt.

## Auf dem Handy spielen

Sobald GitHub Pages aktiviert ist, den Spiel-Link öffnen:

- iPhone: in Safari **Teilen → Zum Home-Bildschirm → Hinzufügen**.
- Android: in Chrome **⋮ → App installieren** oder **Zum Startbildschirm hinzufügen**.

Das Spiel speichert Fortschritt und Upgrades lokal im Browser. Nach dem ersten Laden können die Spiel-Dateien offline bereitstehen.

## Steuerung

- Handy: linker Joystick zum Bewegen, rechter Knopf zum Schießen.
- Tastatur: WASD oder Pfeiltasten, Leertaste oder J zum Schießen, P oder Escape für Pause.

Die Web-App besteht aus den Dateien im Repository-Stamm. Es sind kein Build-Schritt und keine Laufzeit-Abhängigkeiten nötig.
